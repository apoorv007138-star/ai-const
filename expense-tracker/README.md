# Python Expense Tracker

A beginner-friendly command-line app to record daily expenses and understand where your money goes.

## Features

- Add expenses with a description, amount, date, and category
- View all saved expenses
- See total spending and a category-wise breakdown
- Automatically save data in a local JSON file

## Requirements

- Python 3.8 or newer
- No third-party packages required

## Run the project

1. Clone the repository:
   ```bash
   git clone https://github.com/apoorv007138-star/ai-const.git
   ```
2. Open the project folder:
   ```bash
   cd ai-const/expense-tracker
   ```
3. Run the app:
   ```bash
   python main.py
   ```

The app creates `expenses.json` automatically when you save your first expense.

Food, Travel, Shopping, Bills, Education, and Other.
